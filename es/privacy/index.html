Política de privacidad

Última actualización: 14 de noviembre de 2026

1. Contacto

Este es un sitio web no comercial sobre historia de la música. Para preguntas sobre privacidad, escríbenos por Instagram: https://www.instagram.com/bejofftherecord/

2. Alojamiento

Este sitio web está alojado en GitHub Pages, un servicio de GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, EE. UU. Al visitar el sitio, GitHub trata datos técnicos como tu dirección IP, la página solicitada y la hora de la solicitud en registros del servidor, para entregar el sitio y mantenerlo seguro. La base jurídica es nuestro interés legítimo en un sitio seguro y fiable (art. 6.1.f RGPD). GitHub puede tratar datos en EE. UU. Más información: GitHub Privacy Statement.

3. Estadísticas de visitas (GoatCounter)

Para saber qué páginas se leen, este sitio usa GoatCounter (goatcounter.com), un servicio de análisis de código abierto con servidores en la UE. GoatCounter no instala cookies, no guarda direcciones IP y no te sigue por otros sitios web. Solo cuenta visitas a páginas, el sitio de procedencia, el navegador, el tamaño de pantalla y el país. Las visitas únicas se estiman con un hash de corta duración que no permite identificarte. La base jurídica es nuestro interés legítimo en saber qué contenidos se leen (art. 6.1.f RGPD). No se guarda nada en tu dispositivo, por eso no hace falta un aviso de cookies.

4. Videos incrustados

Los videos se muestran primero como marcador de posición. Solo al hacer clic en "Ver video" se carga el reproductor de TikTok de TikTok Technology Limited, 10 Earlsfort Terrace, Dublín 2, Irlanda. TikTok recibe entonces datos como tu dirección IP y puede instalar cookies. Al hacer clic das tu consentimiento (art. 6.1.a RGPD). Los enlaces a TikTok, Instagram y YouTube son enlaces normales; al abrirlos se aplica la política de privacidad de cada proveedor.

5. Fuentes

Todas las fuentes están alojadas en este sitio web. No se establece ninguna conexión con Google Fonts ni con otros servicios de fuentes.

6. Tus derechos

Tienes derecho de acceso, rectificación, supresión, limitación del tratamiento, portabilidad y oposición (arts. 15 a 21 RGPD), y derecho a retirar tu consentimiento en cualquier momento. También puedes presentar una reclamación ante una autoridad de control de protección de datos, por ejemplo la Comisionada de Berlín para la Protección de Datos y la Libertad de Información.
